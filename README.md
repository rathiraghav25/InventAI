# InventAI

A modern multi-tenant inventory and billing platform built with React, TypeScript, and Vite for small and medium businesses.

## ✨ Features

- Dashboard with business overview
- Inventory management
- Order management
- Billing & Invoice generation
- Customer management
- Business analytics dashboard
- AI Assistant
- Notifications
- Admin settings
